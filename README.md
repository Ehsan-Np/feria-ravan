# فریا روان (Feria Ravan) — مخزن پروژه

سامانهٔ جامع تست‌های روان‌شناسی، کارگاه، دوره و رزرو مشاوره — **PHP 8 + MariaDB**، کاملاً فارسی و راست‌چین، بدون هیچ وابستگی خارجی (بدون CDN/Composer).

این مخزن «هاب پروژه» است و سه بخش دارد:

```
feria-ravan/   ← سورس کامل محصول (نسخهٔ ۳٫۰٫۰) — همان پوشه‌ای که روی هاست آپلود می‌شود
docs/          ← مستندات پروژه از جمله مجموعهٔ پرامپت‌های توسعه
qa/            ← مجموعهٔ رانرهای تست خودکار (۱۶ اسکریپت) که در توسعهٔ هر نسخه استفاده شده‌اند
```

## نصب محصول
1. پوشهٔ `feria-ravan/` را روی هاست (Apache/Nginx + PHP 8.0+ + MySQL/MariaDB) آپلود کنید.
2. به آدرس `/install` بروید و مراحل نصب گرافیکی را دنبال کنید؛ `config.php` قالب خام است و نصب‌کننده آن را با اطلاعات دیتابیس شما پر می‌کند. **هیچ رمز واقعی در مخزن وجود ندارد.**
3. پس از نصب، پوشهٔ `/install` را حذف کنید.

مستندات کامل‌تر محصول: [`feria-ravan/README.md`](feria-ravan/README.md) (تاریخچهٔ کامل نسخه‌های ۱٫۰ تا ۳٫۰).

## رانرهای تست (qa/)
اسکریپت‌های PHP که در پایان توسعهٔ هر نسخه اجرا شدند و باید سبز بمانند؛ برای استفاده نیاز به یک نمونهٔ نصب‌شدهٔ محصول با دیتابیس تست است (`BASE` و اطلاعات دیتابیس داخل هر فایل تنظیم می‌شود).

| نسخهٔ اصلی | رانر | تعداد سناریوها |
|---|---|---|
| نصب‌گر ۱٫۷ | `q17.php` | چرخهٔ کامل نصب |
| ۲٫۶ (DISC) | `qa-disc.php` | چک‌های گزارش DISC |
| ۱٫۸→۱٫۹ | `qa-v18.php`, `qa-v19.php` | ۶۰ |
| ۲٫۰→۲٫۹ | `qa-v20.php` … `qa-v29.php` | ۳۴ تا ۹۵ در هر نسخه |
| ۳٫۰ (بیعانه و یادآور تصفیه) | `qa-v30.php` | ۸۸ |

## نسخهٔ جاری
**۳٫۰٫۰** — پیش‌پرداخت (بیعانه) برای کارگاه/دوره/نوبت مشاوره + یادآور خودکار تصفیه با لینک پرداخت اختصاصی (جزئیات در `feria-ravan/README.md`).
