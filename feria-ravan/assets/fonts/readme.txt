فونت‌های فارسی سامانهٔ فریا روان
==================================
وزیرمتن (Vazirmatn) با مجوز SIL OFL 1.1 همراه بسته است — منبع: https://github.com/rastikerdar/vazirmatn

قرارداد نام‌گذاری وزن‌ها (در تنظیمات ← فونت‌ها قابل‌تغییر است):
  {Family}.woff2          → وزن ۴۰۰ (معمولی)
  {Family}-Medium.woff2   → وزن ۵۰۰
  {Family}-SemiBold.woff2 → وزن ۶۰۰
  {Family}-Bold.woff2     → وزن ۷۰۰

برای استفاده از فونت دیگر (مثل شبنم): فایل‌ها را با همین الگو این‌جا بگذارید و در
پیشخوان مدیریت ← تنظیمات ← فونت‌ها نام خانواده را انتخاب کنید.
